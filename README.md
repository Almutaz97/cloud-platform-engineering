# Cloud Platform Engineering

A hands-on cloud and platform engineering project focused on building,
operating, securing, and evolving a production-style web application
infrastructure.

The project is developed incrementally, with each stage implemented,
tested, troubleshooted, and documented before progressing to the next.

## Current Phase

### Manual AWS Infrastructure

The current phase focuses on building the AWS infrastructure manually
to develop a strong understanding of the underlying cloud services,
networking, security, availability, monitoring, and operational behavior.

Status: **In Progress**

## Current Objectives

- Build AWS infrastructure from first principles
- Understand the purpose and behavior of each AWS component
- Practice real-world troubleshooting
- Document architecture and engineering decisions
- Apply security and cost-awareness from the beginning
